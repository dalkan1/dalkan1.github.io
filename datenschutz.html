Hosting

Diese Website wird über GitHub Pages (GitHub Inc.) bereitgestellt. Beim Aufruf verarbeitet GitHub technisch notwendige Verbindungsdaten (z. B. IP-Adresse) zur Auslieferung der Seite. Weitere Informationen: Datenschutzerklärung von GitHub.

Keine Tracker, keine Cookies

Diese Website verwendet keine Analyse-Tools, keine Werbung und keine Cookies. Schriftarten und Programmbibliotheken werden vom selben Server geladen.

Demo-Anwendung

Alle Eingaben in der Demo werden ausschließlich lokal im Browser (localStorage) gespeichert und nicht an einen Server übertragen. Über „Demo zurücksetzen“ werden sie gelöscht.

Ausnahme: Beim Öffnen eines PDF-Plans in der Demo wird die Bibliothek pdf.js vom Dienst cdnjs (Cloudflare) geladen; dabei wird Ihre IP-Adresse an Cloudflare übermittelt.
